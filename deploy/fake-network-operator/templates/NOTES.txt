⚡ QUICK START STEPS:
------------------------------------------------------------------------------

1. Verify operator pods are running:
     kubectl get pods -n {{ .Values.namespace }}

2. Apply the sample FakeNicClusterPolicy (if not already applied):
     kubectl apply -f https://raw.githubusercontent.com/MuhmmadAyan/fake-network-operator/main/examples/sample-policy.yaml

3. Activate Fake NIC simulation on a node by labeling it:
     kubectl label node <node-name> {{ .Values.nodePoolLabelKey }}=default

4. Verify advertised extended resources on your node:
     kubectl describe node <node-name> | grep -A5 "Allocatable"
     # Expected:
     #   rdma/rdma_shared_device_a: 64
     #   nvidia.com/hostdev:        8
